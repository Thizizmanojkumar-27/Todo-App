# Todo App

A simple **Todo Application** that helps users manage daily tasks efficiently.  
This project demonstrates core frontend concepts such as task creation, deletion, and UI interaction.

---

## 🚀 Features

- Add new tasks
- Delete completed tasks
- Simple and clean user interface
- Lightweight and fast
- Beginner-friendly project

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** GitHub Pages
- **Tools:** VS Code, Git, GitHub
